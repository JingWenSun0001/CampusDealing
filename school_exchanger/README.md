# CampusDealing

校园二手交易与校内互助工具「校小易」1.0。

## 产品定位

CampusDealing 只服务于单一校园，优先解决不值得邮寄、需要快速线下交接的交易：临期食品、生活用品、大件物品、租借、代取、代买、拼车、票券和校园服务。

它不做全国电商，不做支付收款，不做长聊天，不做社区，也不做代课、代跑、刷课。

## 当前版本

- 移动端优先首页
- 校内服务分类入口
- 两列商品卡片
- 发布信息入口，预留 AI 自动分类
- 独立“我的”页面
- 用户公开身份信息：姓名、学号、宿舍楼和宿舍号

## 本地运行

项目现在使用 Node.js + SQLite 后端，不再依赖浏览器 `localStorage` 作为主数据源。

在项目根目录运行：

```powershell
node server.js
```

也可以使用 npm 启动：

```powershell
npm start
```

然后打开 <http://127.0.0.1:8000>。数据库会自动创建在 `data/campus.db`，首次启动会写入 3 条示例任务。

主要接口：

- `GET /api/posts`：任务列表，支持 `category` 和 `q` 筛选
- `POST /api/posts`：发布任务
- `GET /api/posts/:id`：任务详情
- `POST /api/posts/:id/claim`：抢单
- `GET /api/me`：个人资料和统计
- `PUT /api/profile`：保存个人资料

## 免费部署说明

项目已补充 `render.yaml`，可以用于创建免费的 Node.js 测试服务。当前版本仍使用 SQLite；免费实例可能休眠或重建，因此数据库迁移到 PostgreSQL 之前只适合演示，不适合保存真实用户数据。

## 设计原则

快速看懂、快速发布、快速线下交接。所有功能都服务于“校内见面拿走”，避免把产品做成闲鱼或社区软件。
