# 河小易微信小程序

这是项目的原生微信小程序端，页面通过 Node.js API 读写任务和个人资料。

## 导入方式

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录 `miniprogram`。
3. AppID 可以先选择“测试号”或使用你自己的小程序 AppID。
4. 在 `app.js` 修改 `globalData.apiBase`。

本地开发时，开发者工具可以在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，然后把地址改成电脑局域网 IP，例如 `http://192.168.x.x:8000/api`。

正式发布前必须使用 HTTPS，并在微信公众平台配置 request 合法域名。当前 Node 后端接口无需改动即可配合这套小程序端使用。

## 本地验证

先在项目根目录运行 `npm start`，再在微信开发者工具中点击“编译”。项目根目录运行 `npm test` 可执行前后端自动化检查。

当前身份仍是本地演示用户。正式给多人使用前，必须接入 `wx.login`、服务端会话和校园身份认证，不能把演示用户机制直接发布到生产环境。
