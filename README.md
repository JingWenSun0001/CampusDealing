# CampusDealing

校园二手交易与校内互助工具「校小易」1.0。

## 产品定位

CampusDealing 只服务于单一校园，优先解决不值得邮寄、需要快速线下交接的交易：临期食品、生活用品、大件物品、租借、代取、代买、拼车、票券和校园服务。

它不做全国电商，不做支付收款，不做长聊天，不做社区，也不做代课、代跑、刷课。

## 当前版本

- 移动端优先首页
- 校内服务分类入口
- 两列商品卡片
- 发布信息入口，预留 AI 自动分类
- 独立“我的”页面
- 用户公开身份信息：姓名、学号、宿舍楼和宿舍号

## 本地预览

直接打开 `dist/index.html` 即可预览。首页底部的“我的”会进入 `dist/profile.html`。

## 设计原则

快速看懂、快速发布、快速线下交接。所有功能都服务于“校内见面拿走”，避免把产品做成闲鱼或社区软件。
